# C++ 学习练习

保存 Visual Studio C++ 学习源码、解决方案和工程配置。

## 目录

- C++书写HelloWorld：基础语法、变量、数据类型和输入输出
- 运算符、数组、函数、指针、结构体
- 通讯录管理系统
- 内存四区、函数提高、类和对象、对象的初始化和清理
- 早期练习：从本机 source/repos 收集的 3 个初始练习文件，原文件保留

## 打开练习

使用支持 .slnx 的 Visual Studio 打开对应目录内的解决方案。
保留根目录的 Directory.Build.targets 和 CppConsoleUtf8.h，它们提供共享的中文编码设置。
同一个工程内可能有多个包含 main() 的练习，运行时应按原工程配置选择练习。
这些文件是学习过程的存档，不代表每个练习都已编译通过。
